## Transcript

On my way out of Firefox, I got to learn about several great alternatives on Android, including Cromite, Fennec, and IronFox. However, Fulguris is pretty easy to miss as it belongs to neither the Chromium nor the Firefox family, and yet provides a package that doesn’t fall short in impressing the nerd inside me. You can find it on F-Droid, at least until September 2026.

The following are a few features I loved or found unique in this web browser:
- The address bar acts not only as a search bar like other browsers, but also as a title bar when you’re not typing into it
- It comes preconfigured with several search engines
- It allows you to manage your tabs as named sessions that work like workspaces
- You can choose Hardware-accelerated rendering
- There are modes like forced dark mode, reader mode, and desktop mode
- It has its own Ad blocker working with a local database with automatic updates
- The tab panel can be moved from a “bottom sheet” to a retractable panel of its own
- You can move these UI elements around between top and bottom
- There are separate settings for portrait and landscape modes
- Tab bar can even be switched to horizontal mode, and that shines on the Titan 2, because this device is kind of neither portrait nor landscape
- You can also use a horizontal tab bar for landscape mode on a regular phone, while keeping a vertical tab bar in portrait mode
- By default, you also never need to hit the new tab option, as everything you do inside the address bar, be it trying to navigate or searching, can open a new tab automatically
- For privacy, you won’t be disappointed either, as it has several privacy-focused features, like not only a Stealth mode, but also features like being able to clear browsing data on exit
- It can also be configured to open every external link in Stealth mode
- You can move things around between the main menu and the tab menu, and keep both of them clean from the features you do not need or use
- It supports keyboard shortcuts which can be handy on a device like the Titan 2
- It comes with an almost endless list of settings you can change to tweak around its behavior and visuals, most of which cannot be covered in a video less than an hour long at minimum

I've been using Fulguris as my daily driver on Android for several months now, and apart from a few minor issues, I'm surprised how well it fits in my workflow, though I've not heard anyone talk about.
